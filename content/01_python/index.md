# Programing in Python
Python is a high-level, interpreted programming language known for its readability and versatility. It supports multiple programming paradigms, including procedural, object-oriented, and functional programming. Python's extensive standard library and vibrant ecosystem of third-party packages make it a popular choice for web development, data analysis, artificial intelligence, scientific computing, automation, and more.

## Libraries

#### [Pendulum](https://pendulum.eustace.io/)
Pendulum is a Python library that makes it easier to work with dates and times. It provides a simple and intuitive API for handling time zones, parsing dates, formatting dates, and performing date arithmetic. Pendulum is designed to be a drop-in replacement for Python's built-in datetime module, offering additional features and improved usability.

#### [pypdf](https://pypdf.readthedocs.io/en/stable/)
pypdf is a pure Python library for working with PDF files. It allows you to read, manipulate, and create PDF documents programmatically. With pypdf, you can extract text, merge or split PDFs, add watermarks, and perform various other operations on PDF files.

#### [loguru](https://loguru.readthedocs.io/en/stable/)
Loguru is a Python logging library that aims to simplify logging in Python applications. It provides an easy-to-use interface for logging messages, with features like automatic log file rotation, colored console output, and support for structured logging. Loguru is designed to be more user-friendly and flexible than the built-in logging module.

#### [Pydantic](https://pydantic.dev/)
Pydantic is a data validation and settings management library for Python. It uses Python type annotations to define data models and provides automatic validation and parsing of input data. Pydantic is commonly used in web development and data processing applications to ensure that data conforms to expected formats and types.

#### [Celery](https://docs.celeryproject.org/en/stable/)
Celery is an asynchronous task queue/job queue based on distributed message passing. It is designed to handle real-time operations as well as scheduling tasks. Celery allows you to run time-consuming or periodic tasks in the background, improving the performance and responsiveness of your applications.

### CLI Tools

#### [rich](https://rich.readthedocs.io/en/latest/introduction.html)
Rich is a Python library for rich text and beautiful formatting in the terminal. It allows you to create visually appealing command-line applications with features like syntax highlighting, tables, progress bars, and more. Rich makes it easy to enhance the user experience of terminal-based applications.

#### [argparse](https://docs.python.org/3/library/argparse.html)
Argparse is a built-in Python library for parsing command-line arguments. It provides a simple and flexible way to define and handle command-line options and arguments in your Python scripts. With argparse, you can create user-friendly command-line interfaces for your applications.

#### [Typer](https://typer.tiangolo.com/)
Typer is a modern, easy-to-use library for building command-line interfaces (CLIs) in Python. It is built on top of Click and leverages Python type hints to automatically generate help messages and validate input. Typer is designed to be intuitive and developer-friendly, making it simple to create powerful CLIs with minimal code.

### Machine Learning & Data Science

#### [Jupyter](https://jupyter.org/)
Jupyter is an open-source web application that allows you to create and share documents containing live code, equations, visualizations, and narrative text. It is widely used for data analysis, scientific computing, and machine learning, providing an interactive environment for exploring and presenting data.

#### [NumPy](https://numpy.org/)
NumPy is a fundamental library for numerical computing in Python. It provides support for large, multi-dimensional arrays and matrices, along with a collection of mathematical functions to operate on these arrays efficiently. NumPy is widely used in scientific computing, data analysis, and machine learning applications.

#### [Pandas](https://pandas.pydata.org/)
Pandas is a powerful data manipulation and analysis library for Python. It provides data structures like DataFrames and Series, which make it easy to handle and analyze structured data. Pandas offers a wide range of functions for data cleaning, transformation, aggregation, and visualization, making it a popular choice for data scientists and analysts.

#### [Matplotlib](https://matplotlib.org/)
Matplotlib is a comprehensive library for creating static, animated, and interactive visualizations in Python. It provides a wide range of plotting functions and customization options, allowing users to create high-quality graphs and charts for data analysis and presentation.

#### [Seaborn](https://seaborn.pydata.org/)
Seaborn is a Python data visualization library based on Matplotlib. It provides a high-level interface for creating attractive and informative statistical graphics. Seaborn simplifies the process of creating complex visualizations, such as heatmaps, violin plots, and pair plots, making it easier to explore and understand data.

#### [Scikit-learn](https://scikit-learn.org/stable/)
Scikit-learn is a popular machine learning library for Python that provides simple and efficient tools for data mining and data analysis. It includes a wide range of algorithms for classification, regression, clustering, and dimensionality reduction, along with utilities for model selection and evaluation.

#### [TensorFlow](https://www.tensorflow.org/)
TensorFlow is an open-source machine learning framework developed by Google. It provides a comprehensive ecosystem for building and deploying machine learning models, including support for deep learning, neural networks, and large-scale data processing. TensorFlow offers tools for both research and production, making it a popular choice for machine learning practitioners.

#### [PyTorch](https://pytorch.org/)
PyTorch is an open-source machine learning library developed by Facebook's AI Research lab. It provides a flexible and dynamic framework for building and training deep learning models. PyTorch is known for its ease of use, strong support for GPU acceleration, and a vibrant community, making it a popular choice for researchers and developers in the field of artificial intelligence.

### Web Development

#### [Requests](https://docs.python-requests.org/en/latest/)
Requests is a simple and elegant HTTP library for Python. It allows you to send HTTP requests easily, with support for methods like GET, POST, PUT, DELETE, and more. Requests provides a user-friendly API for handling headers, cookies, sessions, and authentication, making it a popular choice for interacting with web services and APIs.

#### [Httpx](https://www.python-httpx.org/)
Httpx is a fully featured HTTP client for Python 3, which provides sync and async APIs, HTTP/2 support, connection pooling, and more. It is designed to be a modern alternative to the popular Requests library, offering improved performance and additional features for making HTTP requests in Python applications.

#### [FastAPI](https://fastapi.tiangolo.com/)
FastAPI is a modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints. It is designed to be easy to use and to provide automatic interactive API documentation. FastAPI is built on top of Starlette for the web parts and Pydantic for the data parts, making it a powerful choice for building web applications and APIs.

#### [Scrapy](https://scrapy.org/)
Scrapy is an open-source web crawling and web scraping framework for Python. It provides a powerful set of tools for extracting data from websites, handling requests, and managing the crawling process. Scrapy is designed to be fast, efficient, and easy to use, making it a popular choice for web scraping projects.

#### [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/bs4/doc/)
Beautiful Soup is a Python library for parsing HTML and XML documents. It provides a simple and intuitive API for navigating, searching, and modifying the parse tree, making it easy to extract data from web pages. Beautiful Soup is commonly used in web scraping applications to handle poorly formatted or complex HTML.

#### [Flask](https://flask.palletsprojects.com/en/latest/)
Flask is a lightweight and flexible web framework for Python. It is designed to be simple and easy to use, allowing developers to quickly build web applications and APIs. Flask provides essential features like routing, request handling, and templating, while allowing for extensive customization through extensions.

#### [Django](https://www.djangoproject.com/)
Django is a high-level web framework for Python that encourages rapid development and clean, pragmatic design. It provides a comprehensive set of tools and features for building robust web applications, including an ORM, authentication, admin interface, and templating engine. Django follows the "batteries-included" philosophy, making it a popular choice for developers looking to build scalable and maintainable web applications quickly.

#### [SQLAlchemy](https://www.sqlalchemy.org/)
SQLAlchemy is a powerful and flexible SQL toolkit and Object-Relational Mapping (ORM) library for Python. It provides a high-level interface for interacting with databases, allowing developers to work with database records as Python objects. SQLAlchemy supports a wide range of database backends and offers features like connection pooling, transaction management, and schema generation.

### Development Tools

#### [Python-dotenv](https://saurabh-kumar.com/python-dotenv/)
Python-dotenv is a Python library that allows you to read key-value pairs from a .env file and set them as environment variables. This is useful for managing configuration settings, such as API keys and database credentials, in a secure and organized way. Python-dotenv makes it easy to load environment variables into your Python applications.

#### [Poetry](https://python-poetry.org/)
Poetry is a dependency management and packaging tool for Python. It simplifies the process of managing project dependencies, building packages, and publishing them to PyPI. Poetry uses a pyproject.toml file to define project metadata and dependencies, providing a streamlined workflow for Python developers.

#### [Black](https://black.readthedocs.io/en/stable/)
Black is an uncompromising code formatter for Python. It automatically formats your Python code to adhere to a consistent style, making it easier to read and maintain. Black is opinionated and has minimal configuration options, allowing developers to focus on writing code rather than worrying about formatting details.

#### [isort](https://pycqa.github.io/isort/)
isort is a Python utility for sorting and organizing import statements in your code. It automatically arranges imports into sections (standard library, third-party, local) and sorts them alphabetically within each section. isort helps maintain a clean and consistent import structure, improving code readability.

#### [Mypy](http://mypy-lang.org/)
Mypy is an optional static type checker for Python. It allows you to add type annotations to your Python code and checks for type consistency at compile time. Mypy helps catch potential type-related errors before runtime, improving code quality and maintainability.

### Testing Tools

#### [Unittest](https://docs.python.org/3/library/unittest.html)
Unittest is a built-in testing framework in Python that provides a way to create and run tests for your code. It is based on the xUnit architecture and allows you to define test cases, test suites, and test runners. Unittest supports features like setup and teardown methods, assertions, and test discovery, making it a useful tool for ensuring code quality and reliability.

#### [Pytest](https://docs.pytest.org/en/stable/)
Pytest is a popular testing framework for Python that makes it easy to write simple and scalable test cases. It supports fixtures, parameterized testing, and a rich ecosystem of plugins, allowing developers to create comprehensive test suites for their applications.

#### [Coverage.py](https://coverage.readthedocs.io/en/coverage-5.5/)
Coverage.py is a tool for measuring code coverage in Python programs. It tracks which parts of your code are executed during testing, allowing you to identify untested code paths. Coverage.py provides detailed reports and visualizations, helping developers improve their test suites and ensure that their code is thoroughly tested.
